CO-5 denial code: the procedure doesn't fit the place of service

Clearia · October 2026 · denial codes, read properly

Denial code CO-5 is the payer saying: "The procedure code/type of bill is inconsistent with the place of service." In short: Usually the place of service on the claim is wrong, or the code can't be billed in that setting. Recoverable with a corrected claim when the record shows where the service actually happened.

What the payer is asserting

Two fields on the claim disagree. On a professional claim, that's the procedure code and the place of service code, the two-digit code that says where the patient was seen. On a facility claim, it's the procedure and the type of bill. It isn't a judgment about the care. It's an edit that caught a combination the payer's system won't accept.

Where it comes from in ortho, spine and pain

The settings that matter most are in the CMS place of service code set: office (11), off-campus outpatient hospital (19), on-campus outpatient hospital (22) and ambulatory surgical center (24). The usual causes:

  • A case done in a surgery center billed with the office code, because that's the default in the charge-entry template.
  • An outpatient hospital case coded as on-campus when the department is off-campus, or the reverse.
  • An injection or a procedure that a payer only allows in certain settings, billed from a setting it doesn't accept.

The quieter version: the wrong rate

Place of service doesn't only trigger denials. Under Medicare's physician fee schedule, it decides which rate applies: CMS pays the facility or the non-facility rate based on the place of service on the claim, and the non-facility rate is higher because it covers the practice's own overhead. If your commercial contracts price off the Medicare fee schedule, the same split usually carries over. So a wrong code that doesn't trigger CO-5 still pays the wrong amount. An office procedure coded as facility gets paid less than it should. A facility case coded as office gets paid more, and that money tends to come back later as a recoupment. The fix

  1. Check the record for where the service happened. The operative note, the facility, the schedule.
  2. If the code was wrong, send a corrected claim with the right place of service, inside the payer's corrected-claim window.
  3. If the code was right, it's a coverage question, not a billing error. Ask the payer which settings the procedure is payable in. A denial saying the setting itself isn't payable usually comes as CO-58 instead.
  4. If CO-5 repeats, fix the template or the default in charge entry once. One corrected setting stops the whole pattern.

Source: the code descriptions on this page are quoted from the X12 Claim Adjustment Reason Code list, the standard code set every payer remittance uses.

Questions people ask about CO-5

What does denial code CO-5 mean?

The payer says the procedure code on the claim doesn't fit the place of service reported, for example a surgery center case billed as if it were done in the office.

How do I fix a CO-5 denial?

Confirm where the service happened from the record, then send a corrected claim with the right place of service code. If the place was right, ask the payer which settings the code is payable in.

What's the difference between CO-5 and CO-58?

CO-5 flags a mismatch between two fields on the claim. CO-58 says the payer treats the place of service itself as inappropriate for the service, which is a coverage question rather than a billing error.

Can the wrong place of service change what I'm paid without a denial?

Yes. Medicare pays a facility or a non-facility rate depending on the place of service, so a wrong code can pay less than it should, or more, which tends to come back later as a recoupment.
